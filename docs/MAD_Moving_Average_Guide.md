## 1. MAD 離群值檢測

### 什麼是 MAD？

MAD（Median Absolute Deviation，中位數絕對偏差）是一種穩健的離群值檢測方法，不像標準差那樣容易被極端值拉偏。

### 計算步驟

以某料號月度出貨量 `[39400, 18600, 38400]` 為例：

**Step 1：計算中位數**
```
排序後：[18600, 38400, 39400]
中位數 = 38400（中間值）
```

**Step 2：計算每個值與中位數的絕對偏差**
```
|39400 - 38400| = 1000
|18600 - 38400| = 19800
|38400 - 38400| = 0
```

**Step 3：取偏差的中位數 = MAD**
```
偏差排序：[0, 1000, 19800]
MAD = 1000（中間值）
```

**Step 4：轉換為等效標準差**
```
σ_equivalent = MAD × 1.4826 = 1000 × 1.4826 = 1482.6
```
> 1.4826 是統計常數，使 MAD 與正態分佈的標準差等效。

**Step 5：設定上下界（3倍標準差）**
```
下界 = 中位數 - 3 × σ = 38400 - 3 × 1482.6 = 33952.2
上界 = 中位數 + 3 × σ = 38400 + 3 × 1482.6 = 42847.8
```

**Step 6：判斷離群值**
```
39400 → 在 [33952, 42848] 範圍內 → 正常
18600 → 低於 33952 → 離群值！移除
38400 → 在範圍內 → 正常
```

**結果：**
- 移除離群值後：`[39400, 38400]`
- 月均需求：38,900（原本 32,133）
- 標準差：707（原本 11,731）
- 安全庫存大幅降低

### 什麼時候該啟用？

| 情境 | 建議 |
|------|------|
| 正常銷售品項 | 啟用 — 過濾異常大單或退貨 |
| 新品（< 3 個月資料） | 不影響 — 樣本太少時自動跳過 |
| 季節性商品 | 啟用 — 搭配月份篩選使用 |
| 專案型出貨（大量不規則） | 考慮停用 — 大單可能是正常需求 |

### 系統設定

在計算頁面的「計算策略」區：
- **MAD 方法**：開關切換（預設啟用）
- 啟用時：自動檢測並排除 3σ 以外的離群值
- 停用時：所有月份資料直接用於計算

## 2. 移動平均平滑

### 什麼是移動平均？

移動平均（Moving Average）是一種時間序列平滑技術，用滑動窗口的平均值取代原始值，降低短期波動的影響。

### 計算步驟

以月度出貨量 `[39800, 33500, 46100]`、窗口 = 3 為例：

**Step 1：逐月計算窗口平均**
```
第 1 月 [39800]         → 窗口內只有 1 個值 < min_periods(2) → 保持原值 39800
第 2 月 [39800, 33500]  → 窗口內有 2 個值 ≥ min_periods(2) → 平均 = 36650
第 3 月 [39800, 33500, 46100] → 窗口內有 3 個值 → 平均 = 39800
```

**結果：**
```
原始值：  [39800, 33500, 46100]  → σ = 6300
平滑後：  [39800, 36650, 39800]  → σ = 1819
```

標準差從 6,300 降到 1,819，安全庫存隨之降低。

### 窗口大小的影響

| 窗口 | 效果 | 適用場景 |
|------|------|---------|
| 2 個月 | 輕度平滑，保留較多波動 | 短期趨勢變化快的品項 |
| 3 個月（預設） | 中度平滑，平衡反應速度與穩定性 | 大多數品項的最佳選擇 |
| 6 個月 | 強力平滑，消除季節波動 | 長期穩定品項 |
| 12 個月 | 幾乎完全平滑 | 需要年度趨勢的分析 |

### 系統設定

在計算頁面的「計算策略」區：
- **移動平均**：開關切換（預設停用）
- **窗口大小**：啟用後出現滑桿，可設定 2-12 個月
- `min_periods = 2`：窗口內至少需要 2 個數據點才計算平均

## 3. 兩者的交互作用

### 執行順序

```
原始月度資料
    │
    ▼
① 填補缺失月份（補零）+ 排除未完成月份
    │
    ▼
② 移動平均平滑（如果啟用）
    │
    ▼
③ MAD 離群值檢測（如果啟用）
    │
    ▼
④ 計算 mean、std_dev
    │
    ▼
⑤ 計算安全庫存 SS = Z × σ × √(LT/30)
```

### 搭配使用的效果

| 設定 | 月均需求 | 標準差 | 安全庫存 | 說明 |
|------|---------|--------|---------|------|
| 都不啟用 | 39,800 | 6,300 | 12,915 | 原始計算 |
| 只啟用 MAD | 39,800 | 6,300 | 12,915 | 此例無離群值 |
| 只啟用 MA(3) | 38,750 | 1,819 | 3,729 | 波動被平滑 |
| 兩者都啟用 | 38,750 | 1,819 | 3,729 | 先平滑再檢測 |

> 上表以 SKU `235M202003151` @ Site 1002 為例，Z=2.05(A類)，LT=30天。

## 4. 實務操作建議

### 建議的預設設定

適合大多數情境的穩健設定：

```
MAD 離群值檢測：啟用
移動平均：停用
前置期：依實際採購週期設定
最少月數：2 個月
```

### 什麼時候該啟用移動平均？

1. **資料月數 ≥ 6 個月**：移動平均在短資料下效果有限
2. **品項需求波動大但趨勢穩定**：MA 能降低隨機波動
3. **想要降低安全庫存水位**：MA 平滑後 σ 變小 → SS 變小

### 什麼時候不該啟用移動平均？

1. **資料只有 2-3 個月**：窗口 ≥ 資料長度時效果有限
2. **需求有明確趨勢（上升/下降）**：MA 會滯後
3. **需要保守的安全庫存**：MA 會降低 SS，增加缺貨風險

### ABC 分類與服務水準的搭配

| ABC 等級 | 佔營收比 | 預設 Z 值 | 服務水準 | 策略 |
|----------|---------|-----------|---------|------|
| A 類（重點） | 前 80% | 2.05 | 98% | 高備貨，不允許缺貨 |
| B 類（一般） | 80-95% | 1.65 | 95% | 適中備貨 |
| C 類（次要） | 後 5% | 1.28 | 90% | 低備貨，可接受偶爾缺貨 |

### 計算公式速查

```
安全庫存 SS = Z × σ_monthly × √(LT / 30)

再訂購點 ROP = (月均需求 / 30) × 前置天數 + SS

最大庫存 Max = ROP + SS

變異係數 CV = σ / μ （CV > 1 表示需求極不穩定）
```

## 附錄：名詞對照

| 中文 | 英文 | 說明 |
|------|------|------|
| 月均需求 | Mean Monthly Demand | 完整月份的平均出貨量（含補零月） |
| 標準差 | Standard Deviation (σ) | 需求的波動程度 |
| 變異係數 | Coefficient of Variation (CV) | σ/μ，無量綱的波動指標 |
| 安全庫存 | Safety Stock (SS) | 緩衝庫存，防止缺貨 |
| 再訂購點 | Reorder Point (ROP) | 庫存降到此水位時應下單 |
| 前置期 | Lead Time (LT) | 從下單到到貨的天數 |
| 離群值 | Outlier | 偏離正常範圍的異常數據 |
| 移動平均 | Moving Average (MA) | 滑動窗口平均的平滑方法 |
